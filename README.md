### 部品物流システムのシステム構成変更【JavaScript/Java】(2023 年 4 月 〜 2024 年 3 月)

【プロジェクト概要】オンプレミス環境から AWS への移行を軸に、Java のバージョンアップ（1.8 から 11 への移行）、さらに MS Edge から Chrome へのブラウザ対応といったシステム基盤の大幅な刷新を実施。

【業務内容】WBS の作成を通じてプロジェクト全体のスケジュール管理を行い、方針書や手順書などの各種ドキュメント作成を担当。また、技術検証を実施し、SFTP 接続に必要なライブラリの調査および選定。

【発揮したバリュー】自身が作成した方針書・手順書が、その高い再利用性と分かりやすさから、同社内の他プロジェクトにおいても流用される成果を達成。統一されたドキュメントの活用により、各プロジェクトでの作業手順や運用ルールの一貫性を確保し、全体の業務品質の向上に貢献。
